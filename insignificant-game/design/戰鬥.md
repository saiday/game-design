# 戰鬥

> 第二根支柱：只在戰鬥使用的一副牌，在單一戰場上出牌。軍費直接從錢扣（可到負）——**錢＝生命**的落點就在這裡：贏不難，難的是**用最小軍費贏**。
> 被誰餵：[[地圖與機會|地圖節點]]、[[卡牌|牌組]]、錢（軍費）、[[對手文明]]（文明戰爭、心戰命中率減益）、[[內亂與失敗]]（內亂權重）、[[國策]]（偵查分支：開戰前情報）、[[營運]]（軍事區老兵被動、兵營線勳章）。餵給誰：錢（賠償／損失）、牌組（戰後獎勵卡、單位經驗與勳章）、戰功歸屬（[[世界大戰]]）、失敗鏈、[[民主]]（為民主而流血強制進入）、[[對手文明]]（戰敗累計／power±／併吞）、[[幸福]]（內亂鎮壓動用機械型部隊的代價）。

## 戰場結算法（單一戰場・自動佈陣・敵方分波）

- **一個戰場，不分路**。**出牌的唯一限制是軍費**：願意付錢，可以把所有部隊都擺上戰場。沒有手牌、沒有抽牌、沒有出牌位——牌組裡任何一張未出的卡，任何一個回合都能出。
- **每張卡每場只出一次**：出過即進棄牌區（[[卡牌]]）。這是「留後手」有代價的唯一來源——主力全押第一波，第三波就沒東西可打。
- **自動佈陣**：單位依戰鬥屬性自動就位——**工事線**（最前）、**近戰列**、**遠程列**（後排）、**空域**（不佔地面位）；技能卡全域生效。玩家不指定位置。
- **敵方分波投入**：敵方不是一次全上，而是依**波次表**（見戰鬥類型表）在指定回合投入。波次的時點與組成在**開戰時**以 `battle` 亂數軌於表列區間內**抽定**——同一種仗，每場都不一樣。
- **存活延續**：一波打完沒死的單位**留在場上**進入下一波，敵我皆然。上一波沒清乾淨，下一波就疊在殘兵上——落後就會被淹沒。
- **每回合＝一個固定 tick 窗口**：出牌與軍費在**回合邊界**結算，戰鬥在窗口內連續進行。單位**依各自攻速行動、不同時出手**——快的先打，先打的活下來（沒有同時結算，沒有互相抵銷的同歸於盡）。近戰列互擊（敵方近戰列清空後改打其地面後排；**近戰不可攻擊空域**）、遠程列自由選目標（**含空域**）、空襲任選**地面**目標、帶攻城／空襲者可癱瘓工事（見下「工事卡」）；射向空域單位的攻擊一律繞過工事線。HP≤0 移除並記錄清除者（戰功歸屬用）。
- **單位品質（僅玩家部隊）**：**只有玩家的部隊**有**命中率／閃避率／攻速**三項——每張卡取得時抽定、隨使用成長（[[卡牌]]）。攻擊力與血量固定於卡表、不抽。玩家的遠程單位命中率低於 100%。**敵方（正規軍與非正規軍皆然）無品質三項**，以引擎預設結算：命中率 100%、閃避率 0%、攻速 1.0（每回合窗口出手一次）——這三個預設值＝校準項（見下「對手兩型」）。挑戰來自敵方的數值、波數與時代係數，不來自敵方的閃避與攻速。
- **勳章**：單位經驗填滿即在**該 tick 當場獲得勳章**（畫面看得到），效果自**下一回合**生效（[[卡牌]]）。
- **勝負（每回合結算後檢查，雙方對稱）＝耗盡**：一方**場上清空、且已無可投入者**（敵方：波次出完；玩家：未出卡出完，**或還有未出卡但選擇不出**）→ 另一方若場上仍有**陸軍部隊**則勝（只剩空中單位不算拿下戰場，**敵我皆然**）；若此時另一方**僅剩空中單位**，戰鬥**繼續**——雙方都可能在後續回合投入陸軍（玩家出牌、敵方等波次）——直到有陸軍落地取勝，或回合上限到＝判輸照舊（世界大戰無上限：戰局不再可能變化時立即結算，見[[世界大戰]]僵局判定）。工事不是部隊、不計入「場上清空」的判定。軍費可扣到負、錢從不擋出牌，所以「知道輸定了、留卡省軍費」是合法的自願認輸（後果同判輸）。場上被清空但還有卡、還想繼續出，戰鬥就繼續——這使**工事卡（買時間）**遠比過去值錢。
- **核心博弈**：多擺一張牌就多燒一筆軍費——玩家博的是**最小花費取勝**，別讓戰鬥的軍費拖垮經濟。押太少被波次疊死，押太多白燒軍費。戰鬥 UI 全程顯示「本場已燒軍費 vs 預期賠償」，讓這個博弈看得見。
- **開戰前情報**：符合[[國策]]偵查分支的**當代情報資格** → 開戰前可見**本場抽定的波次表**（何時來、來什麼）；未達標＝盲打（見[[國策]]）。波次每場抽定，情報賣的正是這個抽選結果——這是偵查線的價值所在。**衛星監控（偵查終端）額外**：戰鬥中每個回合邊界、在你出牌前**預覽敵方下一回合的實際投入與殘場**——含存活延續的殘兵與下一波，比靜態波次表多的是即時戰場狀態，這是終端獨有的加值（[[國策]]）。
- **工事卡（失效–修復模型）**：出到工事線，本場**永不移除**——工事**被命中一次即失效（被禁用）**，以待修狀態留在場上，直到修復再啟用。**盾陣**攔截一次射向我方地面單位的**近戰**攻擊（無視攻擊力，攔下即失效）；**防空飛彈**（工業時代起才有形態）不攔截、**主動對空開火**：每回合對一個空域單位開火，**命中即擊落**——工事無攻擊力數值，正如它擋下攻擊時無視攻擊力，它開火時也無視血量（一發飛彈就是一架飛機）。以引擎預設結算（命中 100%、每回合一發，無品質三項；目標的閃避率照常生效）。帶攻城／空襲者**優先癱瘓運作中的敵方工事**（無需命中骰、一擊即失效）；已失效的工事不再是目標。**工兵團每回合修復一個待修工事**——不限工事失效時誰在場，後續波次投入的工兵照修；多個待修依序輪流、每個一回合。同場上限 2。
- **敗北的兩個觸發、後果相同**：回合上限到仍未分勝負（判輸）與耗盡（場上清空且無可投入／選擇不出）都是**敗北**，同吃該類型「敗北後果」欄——無賠償、已燒軍費沉沒；內亂／獨立戰另吃失敗鏈損失（[[內亂與失敗]]）。判輸**不套用**主動撤軍的 +2 人口與費用（那是玩家按撤軍才有）。**[[世界大戰]]無回合上限**（改以波數上限節流、觀看模式續打至耗盡定勝負）。戰鬥的經濟壓力全部由軍費承擔，沒有其他直擊國庫的懲罰通道。
- **戰後獎勵卡**：每場戰鬥結束——**勝敗皆然、七種類型皆然**——隨機亮出一張獎勵卡（首見免費納入、重複卡付 5×時代係數 收編；池與完整規則見[[卡牌#卡牌經濟]]）。讓步／戒嚴取消的戰鬥沒打、不發；投誠＝勝、照發。類型表「敗北後果」欄的「無賠償」指金錢，獎勵卡照發。
- **撤軍**：隨時可主動按，付 10×時代係數 錢；撤軍永久 +2 人口（人放回去）。打到一半發現吃不下下一波，這是逃生口。**三個型別禁用撤軍**：內部暴動戰、為民主而流血、[[世界大戰]]（全員選邊、無退出口）——這些仗只能打，或用該型別自己的花錢出口（內亂戰的讓步；世界大戰無）。
- **對手兩型（皆無品質三項）**：只有玩家的部隊抽定品質＋老兵＋勳章；敵方一律無品質三項（以引擎預設結算，見上）。**非正規軍**（海盜、外星人、內亂暴民、抗爭群眾、抗稅雜兵、一般地圖戰流寇）用匿名級別（數值×時代係數）——弱＝攻1/血2、中＝攻2/血4、硬＝攻3/血6；**佈陣預設近戰列**，波次表標記「帶攻城／空襲」者具對應癱瘓工事能力（並就位遠程／空域）。**首領＝硬級（匿名級別 `hard`）**：針對「非首領」的技能卡只作用於非硬級（`weak`／`medium`）的非正規軍單位（[[卡牌]]）。**正規軍**（[[對手文明|文明]]對手：文明戰爭、[[世界大戰]]）用**與你相同的真實兵種名冊**（隨時代演化，攻／血取卡表基準值×時代係數，佈陣依名冊各兵種所屬列，不抽不練無勳章、無品質三項）——正規軍無首領／非首領之分，「非首領」技能對正規軍一律無效。兩型皆再乘難度係數 ×(1+0.20d)（d：Easy −1／Normal 0／Hard +1，最低 1；公式全文見[[對手文明]]）。
- **無盾值**：防禦靠工事卡、閃避率或速殺。

- **戰功**＝該文明累計「清除的敵方單位實力總和」（實力＝攻+血）；**最後一擊**＝清掉敗營最後一個單位。攻速決定誰先出手，清除者的歸屬因此比過去更明確。
- 投誠只適用敘事說得通的小規模戰（一般地圖戰）；文明戰爭用心戰、內亂用讓步——三者不重疊。
- **鎮壓的手段有代價**：內亂型戰鬥（內部暴動戰）中，我方出過任何**機械型部隊卡**（[[卡牌]]）→ 戰鬥結束時幸福 −15，**勝敗皆然**、每場一次（[[幸福]]、[[內亂與失敗]]）——對自己人民出動戰爭機器，人民記得。戰鬥 UI 在內亂戰中於機械型卡上標明此代價。

## 場景呈現（戰場場景）

- 戰鬥是三個主場景之一（城市／地圖／戰場，總述見[[營運]]）：進戰即切到**專屬戰場畫面**，城市退出畫面。
- **每種戰鬥類型有自己的戰場背景**（對應戰鬥類型表的 7 型）：背景先讓玩家看懂「這是哪種仗」——收稅／地圖戰的野戰郊野、隱藏戰的異象之地（海盜／外星人）、內部暴動的城內街壘、為民主而流血的廣場、文明戰爭與世界大戰的大戰場；具體美術於資產關卡由人類定案。
- 自動佈陣的規則直接決定畫面結構：雙方相對，各自由前到後＝工事線 → 近戰列 → 遠程列 → 空域；技能卡全域生效不佔位。**前後即掩護**：近戰列擋在遠程列前面（敵近戰必先啃近戰列）、工事線擋在最前——掩體感由畫面的前後遮蔽表達，不用座標。
- **戰鬥是用看的**：回合窗口內，單位依攻速各自出手，命中、閃避、清除、獲得勳章都在它發生的那個 tick 演出。玩家在窗口內不操作——看完這一回合，再到邊界決定下一回合投入什麼。
- **工事讀作建物，不是單位**：無數值標籤，只有**運作中／被禁用**兩種狀態。盾陣平時不搶眼，在**攔截的那一刻**現身擋下攻擊，隨後以被禁用狀態留在原地等工兵修復；防空飛彈在有空域目標的回合真的開火；工兵修復逐回合演出。
- 「**本場已燒軍費 vs 預期賠償**」全程常駐；**未出的卡與回合動作**是場景內的固定 UI 帶（每張卡標示軍費、以及它的命中／閃避／攻速）；內亂型戰鬥依規則在開場標明民怨來源；有情報資格時，本場波次表同場顯示。
- **戰後結算畫面亮出獎勵卡**：含抽定的名稱前綴（糟糕的／可靠的）與品質三項，玩家在此決定納入或放棄；重複卡標明 5×時代係數 的收編價（[[卡牌#卡牌經濟]]）。「太爛就放棄」的決策瞬間就在這一幕。
