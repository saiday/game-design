# 卡牌

> 戰鬥牌組的全部參數：類別、取得管道（購買＋戰後獎勵卡）、起始牌組、軍費、戰場數值、單位品質、成長、用後去向、解散。
> **每張卡是一個有身世的部隊，不是一個數值樣板**：攻擊力與血量由卡表固定，但品質等級（Bad／Medium／Good）與命中率／閃避率／攻速在取得時抽定，並隨使用成長。
> 被誰餵：區域解鎖（唯一購買來源）、科技（時代階級門檻）、戰後獎勵卡（每戰必發，見「卡牌經濟」）、時代演化、[[戰鬥]]（經驗與勳章）、[[營運]]（軍事區老兵、兵營勳章）、[[國策]]（國策限定卡、專利制度解卡費、科技門檻、技能卡軍費）、[[地圖與機會]]（行商／寶藏獎勵卡）、[[Legacy]]（搖滾精神授予「爛仗時候才宣揚愛與和平」）。餵給誰：[[戰鬥]]、人口（解散人數型回收）、錢（解散／解卡費／收編重複卡／重骰）。

## 解鎖規則（購買：區域＋科技＋解卡費）

- **區域開卡池**：民生區→人數型部隊卡；軍事·兵營→機械型部隊卡；軍事·兵工→工事卡＋工兵團（工事的攻防一體）；文化區→技能卡（[[營運]]）。
- **科技開階級**：每張卡有時代階級；科技達門檻（＝時代序×10；[[國策]]「文字與曆法」降為 8×時代序、「政教合一」再 +2×時代序）才能買當代階。卡隨時代**就地演化升級**，不必刪舊買新。
- **解鎖任何卡都要付錢**（解卡費＝10×時代係數；[[國策]]節點「專利制度」使其減半）。**解鎖的瞬間抽定這支部隊的品質等級與品質三項**（見下方「單位品質」）——先付錢、後開品質，買卡是賭；同樣是弓箭團，抽到的部隊不一樣。
- **購買之外唯一的取得管道是戰後獎勵卡**（每場戰鬥結束必發一張，見「卡牌經濟」）。獎勵卡直接給一張卡，**不開購買權**：想買同名卡，仍要區域＋科技門檻＋解卡費。
- **國策不鎖卡、反而給卡**：[[國策]]樹無互斥，任何戰鬥卡都不會被封；四個戰鬥相關的節點各解鎖一張**國策限定卡**（見下表「國策限定」列）——節點完成該卡入池，照付解卡費。兩條特殊規則：
  - **技能類限定卡（勸降廣播、軌道打擊）用後即從牌組永久銷毀**，本局不再取得——一個節點換一次強效果。
  - **部隊類限定卡（聖戰士團、私掠傭兵）與一般部隊卡同規則**：進棄牌區、可付費解散（無回收）、隨時代就地演化、品質等級與品質三項照抽（見下方演化表與品質表）。國策限定卡不進戰後獎勵池——節點是它們唯一的來源。
  - 「戒嚴」是秘密警察授予的主動型 [[Legacy]]（閃避一場內亂），不是卡。

## 起始牌組（開局）

- **起始牌組＝5×步兵團**（牌組下限 5 的開局解）。開局即視為取得的瞬間：五張各自抽定品質等級與品質三項。
- **起始人口 0**（[[營運]]）：開局的人口引擎靠解散步兵團啟動——每解散一張 +2 人口。起始步兵團是這個文明的全部本錢：留著是軍隊，解散是人口。第一場戰鬥後若不解散幾張換人口，人口相關的正成長會很慢（抽稅＝人口×稅率、BP 靠保底 1 撐）。
- 政權崩潰判定（人口 < 5）自人口首次達到 5 後才生效（[[內亂與失敗]]），開局的 0 人口不是敗局。

## 單位品質（取得時抽定）

**只有部隊卡有品質**（工事卡與技能卡沒有：工事以引擎預設結算——防空飛彈的對空開火同敵方單位用預設三值——技能是全域效果）。解鎖／取得該卡的瞬間，以 `cards` 亂數軌**先抽品質等級（Bad 10%／Medium 80%／Good 10%），再在等級對應的帶內抽定三項**，**此後跟著這張卡一輩子**：

| 品質 | 是什麼 | 怎麼用 |
|---|---|---|
| **命中率** | 出手打不打得中 | 遠程單位天生低於 100%（[[戰鬥]]）；近戰穩、砲兵飄 |
| **閃避率** | 被打時閃不閃得掉 | 沒有盾值，閃避是工事以外唯一的減傷 |
| **攻速** | 一個回合窗口內出手幾次 | 決定誰先出手；先出手的活下來 |

### 品質等級（Bad 10%／Medium 80%／Good 10%）

品質等級決定這張卡品質三項的總水位——**它讓「這張牌爛到該放棄」成為真實的決策瞬間**（戰後獎勵卡先亮品質再決定，見「卡牌經濟」）。

| 等級 | 機率 | 三項的抽選帶 | 單位名稱 |
|---|---|---|---|
| **Bad** | 10% | 分布表區間**下方**外擴一個帶寬 | 「糟糕的」前綴：糟糕的步兵團 |
| **Medium** | 80% | 分布表區間本身（現行區間＝Medium 帶） | 無前綴：步兵團 |
| **Good** | 10% | 分布表區間**上方**外擴一個帶寬 | 「可靠的」前綴：可靠的步兵團 |

- **帶的算法**：每格的帶寬＝該卡該項的（上限−下限）。Bad 帶＝[下限−帶寬, 下限]、Good 帶＝[上限, 上限＋帶寬]；夾限：命中率 0–100%、閃避率 0–50%、攻速下限 0.1。例：步兵團命中率 Medium 85–95% → Bad 75–85%、Good 95–100%（夾限自 105%）。
- **等級與品質三項同壽命**：陣亡不重抽（見「陣亡與重骰」）、跨時代演化帶著走（前綴掛在當代形態名上：糟糕的長矛方陣）、解散一併銷毀；同名卡的每份重複卡各自抽等級。
- 10／80／10 的機率與帶寬倍率都是校準旋鈕；**只有玩家的部隊有品質等級與品質三項**——敵方（正規軍與非正規軍皆然）無品質三項，以引擎預設結算（見[[戰鬥]]）。

|---|---|---|---|

- **抽到什麼就是什麼**：一支抽到 Good 的可靠弓箭團是本局的寶；抽爛的那支，要嘛認了，要嘛付費重骰，要嘛解散後賭戰後獎勵卡免費再見到它（見下方「卡牌經濟」）。這是**解散**成為真正營運決策的原因。
- **區間是設計旋鈕**：好的抽選要值得高興、爛的抽選要刺但不到不能用。

## 成長（經驗與勳章）

**練什麼強什麼**——單位的數值就是它的履歷：

| 品質 | 靠什麼累積經驗 |
|---|---|
| 命中率 | **出手攻擊**（打得越多越準） |
| 閃避率 | **被攻擊且活下來**（挨過打才學會閃） |
| 攻速 | **每存活一個回合**（純資歷） |

- **勳章**：某一項的經驗填滿，該單位即在**那個 tick 當場獲得勳章**（[[戰鬥]]：畫面看得到、不暫停），該項 +1 階，**效果自下一回合生效**。
- **成長階 v1 基準**：命中率 +3%／階、閃避率 +2%／階、攻速 +0.1／階。命中率封頂 100%、閃避率封頂 50%；**攻速無封頂**。
- **勳章的兩個來源**：
  1. **戰鬥**：經驗填滿自動獲得，加在**填滿的那一項**，不需玩家選擇。
  2. **軍事·兵營**：建築線產出勳章，玩家在**營運相位指派給任一張卡**（[[營運]]）——這是唯一由玩家挑對象的勳章。玩家挑的是**卡**，成長軸由該卡所屬列固定決定：**近戰列＝攻速、遠程列／空域（轟炸機）＝命中率、工兵團＝閃避率**（工兵團不出手，勳章只墊它唯一的成長軸）。單卡可獲勳章數**無上限**——攻速無封頂，一支近戰主力可持續疊攻速；其增幅靠兵營產出速率與成長階校準，不是結構性封頂。
- **勳章與政體無關**：戰鬥經驗勳章（來源 1）本就自動、不經營運相位——民主與世界大戰代照常在戰場獲得。兵營勳章（來源 2）在民主後（營運相位關閉、[[民主]]）改為**依所屬列自動指派**（玩家已無挑卡動作；自動指派的目標卡預設規則＝校準項），世界大戰整代覆寫的那一代則單純略過該代指派——兩者都不讓兵營成為死建築。
- **軍事區「老兵」被動**：我方單位**起始 +1 成長階**（[[營運]]），成長軸與兵營勳章同規則（近戰＝攻速、遠程／空域＝命中率、工兵團＝閃避率）。這是純戰力、買不到，也是軍事區的唯一基礎被動；作為被動它是**常駐底線**——單位陣亡歸零後回場仍享此 +1，直到失去軍事區為止。
- **[[對手文明]]「文化國」心戰**：你的下場戰我方單位**命中率降低**。

### 陣亡與重骰

- **單位陣亡 → 該卡的已獲成長全部歸零**（含戰鬥與兵營指派的所有勳章），卡本身回到牌組（部隊還在，死的是這批老兵）。下次出場是一批新兵，從抽定值重新練起；若仍有軍事區，回場即享老兵的 +1 底線（見上）。
- **陣亡不重抽品質等級與品質三項**：抽定值是這支部隊的**訓練傳統**（怎麼徵、怎麼練、怎麼打），老兵死了，傳統還在。
- 這條是**刻意的**，不是漏洞：若陣亡會重抽，故意送死就是全遊戲最便宜的重骰（送死只花 2×時代係數 軍費，還幫你擋幾下；解散再解鎖要 18×時代係數）。想重骰就付錢重骰。
- **就地演化全部保留**：抽定的品質等級、品質三項與已獲勳章，跨時代演化時**一律帶著走**（[[卡牌#部隊卡的時代演化總表]]）——所以一支古典時代抽到的黃金弓箭團，可以一路帶到資訊時代；一支抽爛的，也會跟你一整局（除非你解散它）。

## 部隊卡的時代演化總表

所有部隊卡共用一條規則：**就地演化**（換名換皮，數值隨時代係數放大），不刪舊買新。卡表的「卡名」是這張卡的代表名（識別用）；實際 UI 顯示當前時代的形態名。「—」＝該時代此卡尚無形態（科技門檻與解鎖來源自然擋住，最早只能在有形態的時代入池）。演化**只換名與攻血係數**，不動品質三項與勳章。聖戰士團與私掠傭兵的形態**止於某個時代**（見表）：進入下一個沒有形態的時代時，該卡**自動解散**（不收解散費；回收依卡表，之後不再入池）。

## 卡牌經濟

| 規則 | 內容 |
|---|---|
| 牌組大小 | 無上限、下限 5 |
| 起始牌組 | 5×步兵團，開局抽定品質（見「起始牌組」） |
| 每場出牌 | 每張卡每場只出一次（出過即進棄牌區）；**沒有手牌、沒有抽牌**，未出的卡任何回合都能出，唯一限制是軍費（[[戰鬥]]） |
| 解散（刪牌） | **唯一的移除動作，沒有免費移除**：付 8×時代係數 錢；人數型 +2 人口（永久，墊高稅基與 BP）、機械型無回收（沉沒成本）；品質等級、品質三項與勳章一併銷毀（時代演化的自動解散不收費，見演化總表） |
| 撤軍 | 戰鬥中隨時可退，付 10×時代係數 錢；永久 +2 人口（內部暴動戰／為民主而流血／[[世界大戰]]禁用，見[[戰鬥]]） |
| **重骰** | 解散（8×時代係數）→ 再付解卡費（10×時代係數）重新解鎖 → **重抽品質等級與品質三項**。合計 18×時代係數：買的是「現在就換」，而且先付錢後開品質 |
| **戰後獎勵卡** | **每場戰鬥結束必發一張，勝敗皆然**、七種戰鬥類型皆然（讓步／戒嚴取消的戰鬥沒打、不發）。獎勵卡**先抽定品質等級與三項、亮牌後再決定**：**首見**（牌組目前沒有這張卡）＝免費選擇納入或放棄——放棄無代價，下次再抽到同名卡仍算首見、照樣免費；牌組已有＝可付 **5×時代係數** 收編為重複卡。獎勵池＝當前時代有形態的一般卡（國策限定卡與 [[Legacy]] 授予卡不在池內），**不受區域與科技門檻限制**；納入不開購買權 |
| 時代演化 | 卡就地升級當代兵種（換皮換數值），不刪舊買新；品質等級、品質三項與勳章全帶著走 |

## 兩型部隊的取捨（設計意圖）

- **人數型**：便宜、弱、退場回人口——窮局可變現的資產，餵稅基與 BP。抽爛了處理起來不痛：解散拿回 +2 人口，之後戰後獎勵卡再抽到同名卡＝首見、可免費收一支新的。
- **機械型**：貴、強、退場血本無歸——壓縮戰鬥回合數（少燒軍費），代價是無彈性。抽爛了重骰很痛（18×時代係數、解散無回收），抽好了就是本局的核心資產。
- **品質是第三個軸**：兵營線的勳章可以指派、軍事區的老兵墊高起始階——軍事路線買的不是數量，是**質量**。
- 戰鬥是「輸出競速 vs 軍費燃燒」：機械型省時間、人數型省單張成本、工事卡買時間、技能卡是一次性槓桿。一副好牌通常四者都要——而且你會逐漸捨不得那幾支練出來的老兵。
